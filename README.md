# SAPNE - Support Association for Promoting Nationwide Education

Welcome to the SAPNE NGO website project! This is a modern web application built with **React** and **Next.js** to support our mission of promoting education nationwide.

## About SAPNE

**SAPNE** stands for **Support Association for Promoting Nationwide Education**. We are a non-governmental organization dedicated to:

- Providing quality educational resources to underserved communities
- Promoting digital literacy and online learning
- Supporting educational initiatives across the nation
- Building sustainable educational infrastructure

## Project Overview

This project is a Next.js-based web application that serves as the digital platform for SAPNE NGO. It provides information about our programs, initiatives, and allows community members to learn more about our mission.

## Tech Stack

- **Frontend Framework:** React 18
- **Framework:** Next.js 14 (with App Router)
- **Node.js Version:** 20.11.0
- **Package Manager:** npm

## Getting Started

### Prerequisites

- Node.js (v20.11.0 or higher)
- npm (v10.2.4 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Shivamsahal/SAPNE.git
cd SAPNE
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

The application will start on `http://localhost:9999`

### Build for Production

To create a production build:
```bash
npm run build
npm start
```
